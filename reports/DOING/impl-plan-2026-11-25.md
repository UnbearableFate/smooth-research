# Implementation plan: redesign 2026-11-10 (schema 5)

Source: design/site/content/smooth-research-redesign-2026-11-10.md. Working notes; deviations go back into the
design doc at the end (AGENTS.md rule 4).

## Keep (infrastructure)
store.py (+ minimum schema 5), util.py, documents.py (+ owner), labels.py, literature.py, compute.py, usage.py
(statusline only), herdr.py, launch.py, snapshot.py, upgrade.py (mechanism only, tables emptied), hooks.py.

## Rewrite
- schema.py: v5 entities (Task kinds hypothesis/tree/phase/prep/execute; Phase `PH`; Ask `RQ` = decision
  requests, user approvals, phase reports; Ticket rounds with passes and findings; Message = dialogue entries).
- research.py: hypotheses (purpose, ASSUMES, flag, defer, cost), experiments (design commit, manifest, protected,
  semantic tests, brief), evidence, decisions (draft/final; verdict/stop/route/phase; interpretation; highlights).
- tasks.py: create/release/claim/dispatch/deliver/accept/return/block/answer/cancel; worktrees per task; merge
  on accept (merge commit, test, then ff main); phases; asks.
- reviews.py: rounds, segments, max 3 passes, findings (category/severity/status), discussion, escalation to
  advisor ruling.
- runs.py: run category (trial/prep/evidence), OF_TASK, manifest check, deviation, expected end, `rl run ended`.
- inbox.py (new): the rules table; todo per recipient; invariant for doctor; escalation by elapsed time.
- verify.py (new): check lines 9.2 / 9.3.
- refs.py (new): locator validation/expansion (8.6).
- pack.py (new, replaces context.py): five packs.
- watch.py + sessions.py (replace agents.py/messages.py): herdr-only sessions, wake, clear, heartbeat, redraw.
- page.py (replaces explain.py/view.py/manuscript.py): docs/research.html from records, bypass-lora template.
- cli.py: new parser.
- plugin skills/role cards; hosts; tests.

## Delete
adapters.py headless calls (keep Entry/family), delegate.py, manuscript.py, explain.py, context.py, messages.py,
agents.py, agentlog.py (unless retries need it), scope.py (replaced by protected-scope diff), view.py,
upgrade _v2.._v4 + OLDER_LAYOUT, fixtures schema-2..4.
