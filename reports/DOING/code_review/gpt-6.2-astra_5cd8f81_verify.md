## New remote staging regression

**High · A remote Git executor cannot fetch a pending merge candidate through the supported workflow.** Acceptance uses `git commit-tree` and records the candidate in the database without creating a Git ref. The task branch follows it only after acceptance. With main and the delivery diverged, I registered a merge-test attempt, then ran `rl compute sync` from both main and the task checkout against a local bare origin. Both pushes succeeded. The origin had the delivered task branch, but `git cat-file -e` could not find the candidate. The generated staging instructions themselves reported that no local branch contained it. A project requiring remote Git staging cannot run the test needed to advance main. Create a ref for each pending acceptance and have sync and the remote fetch instructions publish and fetch that exact ref. Retire it after reconciliation. `gitops.py:177–194,211–216`, `tasks.py:679–685,720`, `compute.py:261–276,296–299,434–444`

## Architecture, test gaps and validation

The merge-test completion path now carries the attempt, delivery, candidate and round through to the protected write. Reusing that recorded acceptance for local restart and Git transport would remove the need to reconstruct the candidate from current main. The corresponding simplification for scientific work is to use the sealed design identity consistently for dispatch clearance, registration, retries and historical verification.

Add regression coverage at the workflow boundaries. The most important cases are a remote fetch of a pending candidate, interruption after a real fast-forward followed by another mainline commit, automatic public-prep recovery, and return/redelivery of the same hash with a changed conclusion. For evidence, cover a different manifest in the same commit, a revision change during registration, and a current-format retry across handoffs. Preserve the old test-report replay and multiline notification-note cases. Assert the resulting Git refs, graph state and eligibility, alongside CLI output.

No live scheduler job or model session was started for these probes. CodeGraph supplied caller traces. Pyflakes was clean. Ruff 0.17.6 passed `E9,F401,F63,F7,F82`.
